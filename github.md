The Complete Recommended Order
1. Set Up Rulesets: Protect your primary branches (main, dev, release) so no one can accidentally overwrite them.
2. Create Issues: Log the work, features, or bugs that need to be addressed.
3. Create Feature/Fix Branches: Pull a branch off main to work on a specific issue.
4. Pass Ruleset Controls: Submit a pull request, get reviews, pass tests (mandated by your ruleset), and merge.
